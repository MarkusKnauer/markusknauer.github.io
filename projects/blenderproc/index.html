BlenderProc

Photorealistic training data on demand — 3.4k+ stars on GitHub

3.4k★ on GitHub Vision & Datasets October 2023

BlenderProc is a widely used open source procedural pipeline for the fast creation of photorealistic training images for deep neural networks in computer vision.

It renders RGB together with depth, segmentation, normals, and object poses, which makes it a widely used tool for reducing the reality gap in vision and robotics research — including the HOWS-CL-25 dataset built with it.
